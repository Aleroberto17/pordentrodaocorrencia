Política de privacidade

Por Dentro da Ocorrência · atualizada em 25 de setembro de 2026

O que é este aplicativo

É uma ferramenta de uso pessoal, executada no computador do próprio criador do canal, que envia e agenda no YouTube os vídeos produzidos por ele. Não é um serviço aberto: não tem cadastro, não tem outros usuários e não é distribuído.

Que dados são acessados

Ao autorizar o acesso, o aplicativo recebe permissão para duas coisas na conta do próprio criador do canal:

  • Enviar vídeos (youtube.upload): publicar e agendar vídeos, definir título, descrição, tags, miniatura e legendas.
  • Ler dados do canal (youtube.readonly): apenas para confirmar em qual canal o vídeo será publicado, evitando envio para o canal errado.

Nenhum dado de terceiros é acessado. O aplicativo não lê comentários, não acessa dados de espectadores e não coleta informação de nenhuma outra pessoa.

Onde os dados ficam

O token de acesso fica gravado apenas no computador local do criador, num arquivo de configuração da própria máquina. Nada é enviado para servidores de terceiros, não existe banco de dados remoto e nenhuma informação é compartilhada, vendida ou cedida a quem quer que seja.

Como revogar

O acesso pode ser retirado a qualquer momento em myaccount.google.com/permissions, sem depender do aplicativo.

Uso limitado

O uso das informações recebidas das APIs do Google por este aplicativo obedece à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
